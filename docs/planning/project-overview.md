# Project Overview

## Purpose

The purpose of this project is to design, deploy and document a realistic enterprise IT infrastructure based on industry best practices.

Rather than creating an isolated laboratory, the objective is to simulate the complete infrastructure of a small or medium-sized company, including planning, deployment, administration, troubleshooting and technical documentation.

---

## Objectives

The main objectives are:

* Build a complete enterprise infrastructure from scratch.
* Improve Windows Server administration skills.
* Improve Linux server administration skills.
* Gain practical experience with virtualization using Proxmox VE.
* Learn how enterprise networks are designed and managed.
* Document every implementation step and technical decision.
* Develop professional troubleshooting and documentation habits.
* Develop a structured methodology for planning, deploying and maintaining enterprise infrastructure.

---

## Scope

The project aims to simulate a complete enterprise environment, including Windows and Linux servers, centralized identity management, network services, virtualization, monitoring, backup strategies and basic cloud integration.

Every component will be deployed following a realistic implementation process and documented as if it were a production environment.
